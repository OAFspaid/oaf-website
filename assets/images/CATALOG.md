# Image Catalog — assets/images/

Reference descriptions of every asset in `assets/images/` for later analysis and for
replacing generic / AI-generated images (see issue #3). Descriptions are written for
semantic matching (what each image shows, embedded text, and where it could be used).

**Two clear groups:**

- **Branded graphics (PNG)** — contain the OAF logo and marketing copy. Use as promo
  banners / section graphics, NOT as generic "photo" replacements.
- **Real photos (JPG)** — authentic, unbranded deployment photos of real service members.
  These are the replacements for AI-generated placeholder imagery.
